# 智能会议助手 · 产品说明书

## 一、产品是什么
智能会议助手是一款本地部署的语音转写与会议纪要工具。所有音频处理都在你自己的电脑上完成，录音和文字不会上传到任何云端服务器，适合内部会议、涉密讨论等场景。

## 二、运行环境要求
需要 Windows 10 或 Windows 11 系统，显卡建议 NVIDIA GTX 1060 以上（显存 6GB 起），内存至少 8GB，硬盘预留 10GB 空间用于存放模型文件。如果没有独立显卡，也可以在纯 CPU 模式下运行，但转写速度会慢大约 5 倍。

## 三、安装与启动步骤
第一步，双击桌面上的"启动VoiceMind"快捷方式，等待黑色窗口出现"服务启动中"字样。
第二步，打开浏览器，在地址栏输入 http://127.0.0.1:8000 并回车。
第三步，页面左上角会显示模型加载状态，首次使用需要等待约 30 到 90 秒，状态变成"已就绪"后即可开始使用。
第四步，如果要停止服务，双击"停止VoiceMind"快捷方式即可。

## 四、常用功能说明
普通识别：上传音频或视频文件，系统自动提取音轨并转写为文字，支持中文、英文、日文、韩文。
说话人分离：识别内容并区分不同说话人，生成带角色标签的分段文稿，可以导出 TXT 或 SRT 字幕。
关键词检索：输入关键词，系统返回所有命中片段的时间点和内容，支持精确匹配和模糊匹配。
实时录音：点击麦克风按钮后边说边转写，字幕逐句实时显示。
字幕工作台：批量或单个音视频生成同名 SRT 和 ASS 字幕文件，可以直接导入剪映或 Premiere。

## 五、常见问题
问题一：页面打不开怎么办？
先确认黑色命令行窗口是否还开着，如果窗口已经关闭，说明服务停止了，重新双击"启动VoiceMind"即可。

问题二：提示"没有识别到语音内容"怎么办？
通常是麦克风没有拾到声音，检查系统音量设置和麦克风权限，说话时距离麦克风 20 厘米以内效果最好。

问题三：字幕导入剪映后字幕块被自动拉长怎么办？
这是剪映对 SRT 格式的内置处理逻辑（两条字幕间隔超过 2 到 3 秒时会强制延展前一条）。解决办法是改导入同名的 .ass 文件：新建空项目，播放头回到 00:00:00，通过"文本 → 本地字幕 → 导入"选择 .ass 文件。

问题四：人名或专业术语识别不准怎么办？
在热词输入框里填写正确写法（多个热词用空格或逗号分隔），系统会在识别后按读音自动校正，例如把"九九级"纠正为"周潇齐"。
